Working with the board

Arrange
Drag cards. Move the work bay into a labelled site zone to change its handoff time. All other position changes affect layout only.
Connect
Click a card’s output, then a target. Flow carries a workshop event; Requires adds a gate; Informs annotates a relationship. Episode links explain the fixed engine rules.
Try a rule
Add a trigger and an effect. Connect them with Flow. A Requires link from an episode card adds a readiness check. Select the trigger and press Fire. Workshop values remain separate from episode accounts.
Compare
Step advances half a day. Change a scenario input to replay the same actions with new assumptions. The inspector shows changes from the last edit.
Save
Autosave is local to this browser and address. Export/import shares a board file. A checkpoint saves a separate local branch. Shared rooms use Supabase and an edit link.
Keys
V select · C connect · P draw · F fit · Esc cancel · Delete remove · ⌘/Ctrl Z undo · ⇧⌘/Ctrl Z redo. Arrow keys move a selected card; Shift moves it farther.
