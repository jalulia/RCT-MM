# Two-register manual

Separate explanation and document control from operational demonstrations while linking them through one navigation structure.

1. Document cover and identity → contents → numbered specification sections.
2. Use prose, tables and callouts for the explanatory register.
3. Embed operational examples in a distinct terminal register, clearly labeled as examples or live instruments.
4. Separate current specification, research, superseded material and future proposals in appendices.
